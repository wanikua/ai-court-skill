## 怎么装

一行命令：

```
clawdhub install ai-court
```

服务器用 Oracle Cloud 的免费套餐（4核24G），终身免费。

不想用服务器的，本地也能跑：

```
clawdhub install ai-court --local
```

---

## 装完还要做什么

Discord 开发者平台搞一下：

1. discord.com/developers 创建应用 → 加 Bot
2. 打开 Message Content Intent
3. 复制 Token 填到配置里
4. 启动服务

就这几步，不复杂。

---

## 能干什么

在 Discord 里 @我就行：

- 写小红书文案
- 起标题（给你 10 个选）
- 分析数据
- 写邮件

其他部门也一样：
- @工程部 写代码
- @财务部 算账
- @运维部 部署
