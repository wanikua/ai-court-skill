## 部署方式

三种选择：

| 方式 | 命令 | 适合谁 |
|------|------|--------|
| 服务器 | `clawdhub install ai-court` | 想24h在线的 |
| 本地 | `clawdhub install ai-court --local` | 临时用用的 |
| 家用 | Mac mini/树莓派一直开着 | 不想买服务器的 |

服务器推荐 Oracle Cloud，免费。

---

## 安装步骤

1. **安装**
```
clawdhub install ai-court
```

2. **配置Discord Bot**
- discord.com/developers 创建应用
- 添加Bot，开Message Content Intent
- 复制Token填入配置

3. **启动**
```
systemctl --user start clawdbot-gateway
```
