## 这个系统怎么搭

现在做成 Cloud Skill 了，可以一键安装：

```bash
clawdhub install ai-court
```

需要：
1. 一台服务器（推荐 Oracle Cloud 免费的）
2. Discord Bot（去 discord.com/developers 创建）
3. API Key（Claude/OpenAI/其他）

详细教程在这：
github.com/wanikua/boluobobo-ai-court-tutorial
