### 完整笔记内容（建议做成3-4张图）

**第1张：开头**

把 AI 变成团队？3分钟搞定

之前发的AI朝廷很多人问能不能直接用。可以了。

**第2张：部署方式**

三种部署方式：
- 服务器：`clawdhub install ai-court`（24h待命）
- 本地：`clawdhub install ai-court --local`
- 家用：Mac mini/树莓派

**第3张：Discord设置**

安装后需要在Discord开发者平台创建Bot：
1. discord.com/developers 创建应用
2. 添加Bot，开启Message Content Intent
3. 获取Token填入配置
4. 启动服务

**第4张：使用效果**

真实场景：
- @工程部 写个登录API → 自动写代码+提交GitHub
- @财务部 分析本月开支 → 自动账单分析
- @市场部 写条文案 → 自动生成内容
- @运维部 部署服务 → 自动执行
