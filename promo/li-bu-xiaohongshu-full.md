## 很多人问：这个能复制吗

可以了。

我们把整个系统做成了 Cloud Skill。

### 怎么装

**服务器部署（24h 在线）：**
```bash
clawdhub install ai-court
```

推荐用 Oracle Cloud ARM 免费套餐：
- 4核 24G 内存
- 终身免费
- 性能够用

**本地部署（临时用）：**
```bash
clawdhub install ai-court --local
```

Mac/Windows 都能跑，想用的时候开一下就行。

**家用服务器：**
如果你有 Mac mini 或者树莓派一直开着，也可以当服务器用。

## 装完之后要配置一下

需要在 Discord 开发者平台搞一下：

### 1. 创建 Discord Bot
- 访问 discord.com/developers
- 创建应用 → 添加 Bot
- 开启 **Message Content Intent**（重要！）
- 复制 Bot Token

### 2. 填配置
编辑 `~/.clawdbot/clawdbot.json`：
- 填入你的 Anthropic API Key
- 填入刚才的 Discord Bot Token

### 3. 启动
```bash
systemctl --user start clawdbot-gateway
```
