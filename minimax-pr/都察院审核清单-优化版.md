# 都察院审核清单（AI朝廷GUI Demo版）

## 📋 审核目标
确保AI朝廷多agent协作**像真实朝廷运作**，而不是机械的工作流演示。

---

## ✅ 审核维度

### 1️⃣ 角色真实性
- [ ] 每个部门的persona是否鲜明？（不能千人一面）
- [ ] 增强prompt是否让角色"入戏"？（有朝廷官员的语气和立场）
- [ ] 部门之间有没有合理的"派系"差异？（比如户部保守、兵部激进）

### 2️⃣ 协作自然性
- [ ] 部门之间的互动是否像真实讨论？（不能像接力棒传递任务）
- [ ] 有没有合理的"争论"和"妥协"？（真实朝廷会有不同意见）
- [ ] 内阁拟票 → 六部执行 → 都察院监察，流程是否顺畅？
- [ ] @everyone触发时，各部门回复是否有先后逻辑？（不能同时刷屏）

### 3️⃣ 剧本可演示性
- [ ] 观众能否清楚看懂"这是在模拟朝廷办事"？
- [ ] 有没有关键节点的"旁白"或"解说"？（比如内阁拟票后解释这是什么）
- [ ] 演示时长控制在合理范围？（不能让观众等太久）

### 4️⃣ 技术稳定性
- [ ] 所有bot的model配置正确
- [ ] API调用不会因为rate limit卡住
- [ ] 消息顺序不会因为并发而错乱
- [ ] Discord权限配置正确（各部门能@能回复）

### 5️⃣ 内容安全性
- [ ] 不会产出政治敏感内容（毕竟用"朝廷"做比喻）
- [ ] 不会产出品牌攻击性言论（如果演示中提到真实产品）
- [ ] 不会因为AI"自由发挥"跑偏剧本

---

## 🎭 审核通过标准

**观众视角：**
> "哇，这些AI真的像古代朝廷在开会！"（而不是"这些bot在执行工作流"）

**技术视角：**
> 流程稳定，消息有序，不卡不崩

**内容视角：**
> 有趣、安全、符合演示主题

---

## 🔧 优化建议

### 当前问题（基于你之前的清单）
你之前的清单偏向"MiniMax推广"，但实际需求是**展示AI协作架构**。

### 调整方向
1. **去掉品牌相关检查**（不是给MiniMax打广告，只是碰巧用了M2.5）
2. **增加"演示效果"检查**（观众看得懂、看得爽）
3. **增加"角色扮演质量"检查**（每个部门要有个性）

### 具体修改建议
- **内阁拟票**：prompt里加"用简练的文言风格写建议"
- **六部执行**：每个部门prompt里加各自的"办事风格"
  - 户部：保守谨慎，算账精明
  - 礼部：注重形象，擅长包装
  - 兵部：执行力强，但可能过于激进
  - 工部：技术控，喜欢堆参数
  - 刑部：挑毛病专业户
  - 吏部：关注人事和流程
- **都察院监察**：审完后给个"监察奏疏"，总结哪里好哪里需要改
- **@everyone触发逻辑**：加个延迟机制，让各部门"依次发言"而不是同时刷屏
